# Design Specification: KineticWorld

## 1. Design System & Aesthetics
- **Theme**: Futuristic Dark Mode with Cyber Neon Accents & Glassmorphism.
- **Color Palette**:
  - `bg-dark`: `#090d16` (Deep space background)
  - `bg-card`: `rgba(15, 23, 42, 0.7)` with `backdrop-blur-md` and `border border-cyan-500/20`
  - `accent-cyan`: `#06b6d4` (Primary glowing accent)
  - `accent-purple`: `#8b5cf6` (Secondary gradient glow)
  - `accent-green`: `#10b981` (Operational status indicator)
  - `text-main`: `#f8fafc` (High contrast text)
  - `text-muted`: `#94a3b8` (Secondary text)
- **Typography**: Google Fonts (*Outfit* / *Inter* / *Space Grotesk* sans-serif).

---

## 2. Key Component UI Checklist
- [x] **Navbar**: Glassmorphic sticky header with logo, navigation links, and "Get Started" CTA button.
- [x] **Hero**: Dual animated glowing circles, badge pill, gradient text headline, CTA action buttons.
- [x] **Services Cards**: Interactive 3D hover tilt effect, glowing neon icons, feature pills.
- [x] **Portfolio Modal**: High-contrast glass backdrop, sticky header, result metric callouts.
- [x] **AI Playground**: Simulated terminal with typing cursor animation and neon code blocks.
- [x] **ROI Calculator**: Sleek dynamic range slider with live calculated annual savings readout.
- [x] **Lead Form**: Clean floating labels, input focus glows, submit state loading spinner.
- [x] **Footer**: Live operational indicator badge and social navigation.
