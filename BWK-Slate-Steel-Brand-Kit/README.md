# Build with Kinetic - Final Slate & Steel Kit

- 01-Colour-System: brand guide, CSS, JSON, and Markdown handoff.
- 02-Logo-SVG: ink and slate versions of the approved logo layouts.
- 03-Logo-PNG: corresponding transparent exports at 2400 px wide.
- 04-Social: white BWK on slate or ink, with SVG and 1024 px PNG.

  print PDF/EPS files, favicons, and the approved first-refinement reference.

Use the Slate & Steel brand guide as the current colour specification.
The original monochrome guide documents the unchanged logo geometry.
