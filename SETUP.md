# Setup & Environment Guide: KineticWorld

## Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

---

## 1. Backend Setup (`BE/`)
```bash
cd d:/KineticWorld/BE
npm install
npm run dev # Runs server on http://localhost:5000
```

---

## 2. Frontend Setup (`FE/`)
```bash
cd d:/KineticWorld/FE
npm install
npm run dev # Runs Vite dev server on http://localhost:5173
```

---

## 3. Environment Variables
- Backend `PORT` defaults to `5000`.
- Frontend API target defaults to `http://localhost:5000`.
